# Enterprise-AI-Search-and-Research-Assistant

Production-grade enterprise AI research platform for document ingestion, semantic search, RAG pipelines, and AI agents.

## Repository Structure

- `docs/` — Architecture and design documentation
- `backend/` — Go microservices (API gateway, auth, workspace, document, search, audit)
- `ai-services/` — Python services (document processing, embeddings, RAG, agents)
- `frontend/` — Next.js + TypeScript web app
- `infrastructure/` — Docker, Kubernetes, Terraform, Helm
- `scripts/` — Automation scripts

## Getting Started (High Level)

1. Review architecture docs in `docs/`
2. Configure environment variables in `.env.example`
3. Run local stack (to be added in later steps)
